# necessity: QGroundControl talks to this board natively (MAVLink 2), so no
# mavbridge.py equivalent is needed or shipped.

# Same story on macOS: MAVProxy's rline.py does
#     if platform.system() == 'Darwin': import gnureadline as readline
# and never declares it. Prebuilt arm64 wheel, so nothing compiles.
gnureadline>=8.0; sys_platform == "darwin"
# Static checking. Not needed to fly; needed to trust an edit.
pyflakes>=3.0
